Three isolated control flows that drive the auto-dispatch system: enabling a division, disabling it, and handling a new dispatch event. Companion to the system architecture diagram above.

🟢 Enable Auto-Dispatch

Trigger · Admin turns ON
1User enables auto-dispatchfor a division, from the Dashboard
2Server B pulls ready-for-dispatch requestsfetch the L pending items

4Scale up the ECS Fargate poolspin up N tasks to consume the queue

🔴 Disable Auto-Dispatch

Trigger · Admin turns OFF
1User disables auto-dispatchfor a division, from the Dashboard
2Scale in the ECS Fargate poolreduce task count to 0 — stop all workers
⏹ Idle · zero cost until re-enabled
