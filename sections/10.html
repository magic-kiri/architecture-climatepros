10. Cost Projection

Every dollar figure below is lifted as-is from its source design's AWS cost projection. Auto-Dispatch (A) deploys on real AWS infrastructure (§3/§4), so its figures need no relabeling — the original AWS Fargate / ElastiCache / SNS / CloudWatch / EC2 rate cards apply directly. Only B and C's shared AI tier runs on Azure, so its service names are relabeled to their §3 Technology Stack Azure equivalents (Fargate → Azure Container Apps, CloudWatch → Azure Monitor). No new Azure prices are estimated here: Container Apps' consumption pricing and Azure Monitor's rates differ from their AWS counterparts' rate cards, and the source design quantifying this tier was never re-priced against Azure. Treat the B/C figures as directional, pending a real Azure re-pricing pass before they become a budget commitment.

Pending Azure re-pricing — B/C only: the numbers in the shared AI server / vector store block below are the original AWS estimates from C's source design, carried over unchanged under Azure service names. Treat them as a same-order-of-magnitude placeholder, not a quote — get actual Azure Container Apps / Azure Monitor rates before this section is used for a real budget. Auto-Dispatch's (A) figures below need no such caveat: it runs on real AWS.

A Auto-Dispatch

Only the ECS Fargate worker pool is a variable cost — it is the whole point of scale-to-zero. Everything else is fixed or effectively free. Rates are us-east-1 AWS Fargate/ElastiCache/SNS list prices, applied directly — Auto-Dispatch runs on real AWS, so no re-pricing pass is needed.

AWS ECS Fargate cost formula

Task = 1 vCPU / 2 GB → $0.04937 per task-hour (AWS Fargate rate)

monthly_cost = N x H x 30 x (1 x $0.04048  +  2 x $0.004445)
             = N x H x 30 x $0.04937

N = number of ECS Fargate tasks (2 assumed; each handles 20 dispatches concurrently)
H = hours the division is ON per day
