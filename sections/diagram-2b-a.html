4 · Azure Cache for Redis — Infrastructure Layer New
STREAM · dispatch:stream

Tracks incoming dispatch requests per division. Durable buffer between .NET Legacy API and the Container Apps workers.

MUTEX · lock:div:*

Distributed per-division lock. Guarantees sequential, non-parallel processing — no two workers touch the same division at once.

LIST · resp:{dispatchId}:{techId}

Per-technician reply channel. Azure VM API LPUSHes the Accept/Reject; the worker BLPOPs it — instant wake, no polling. EXPIRE 60s self-cleans.
