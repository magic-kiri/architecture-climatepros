3. Technology Stack

Ten layers, three use cases. The existing platform pieces — client apps, the .NET API host, SQL Server, observability — are shared: reused as-is, not rebuilt. New AI-specific infrastructure is scoped per use case: A gets a durable dispatch queue and a worker pool; B and C share a central AI service, an Azure-hosted vector store, and the same self-hosted model stack.

Cloud transform applied throughout: every AWS-specific service named in the three per-use-case source specs — mobile push fan-out, the async worker/queue tier, the app compute host, and the vector store — is translated to its Azure equivalent above. AWS SQL Server is the one deliberate exception, staying on AWS as Stream 1's sole cross-cloud dependency.
